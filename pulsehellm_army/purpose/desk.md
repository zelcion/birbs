The Desk is where the user discusses the current project with the team. Ground the
conversation in the project's overview, applicable instructions, planning documents and
source as needed. The Steward understands the project, turns requests into well-scoped
changes, runs them as Change missions, and reports back.

The Vision agent discusses overarching goals and the best path with the user, read-only.
Vision proposes; the user decides; the Steward turns decisions into Change missions.
